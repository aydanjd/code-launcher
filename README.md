# Code Launcher V16

A Zsh-based developer launcher for macOS and Apple Silicon.

## Features
- Interactive C, C++, Python, JavaScript, and Java environments
- C and C++ workspaces
- Quick Compile & Run
- Project Creator and Workspace Manager
- System Dashboard and btop monitoring
- Developer Health Check and Update Center
- Apple Silicon Diagnostics
- Ollama AI Center and server management

## Requirements
- macOS and Zsh
- Homebrew recommended
- Optional: btop and Ollama

## Launch
```zsh
zsh ./code.sh
```
